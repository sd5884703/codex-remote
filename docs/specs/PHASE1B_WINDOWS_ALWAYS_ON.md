# 规格：编码遥控 · 第一期 B（双系统登录后自动启动）

## 目标摘要
Mac / Windows 都能装「登录后自动启动」：登录电脑后后台自动跑编码遥控。向导按系统显示中文说明。顺序仍是**先Tailscale（在自己的设备之间建立加密私有网络），再开服务**。电脑服务要能感知当前系统。Linux 仅用于测试环境，不作为给用户的发行包装。

## 非目标
安装包、唤醒已睡眠电脑、多命令行助手、安卓 `.apk`、真机商店上架、Linux 发行版包装。

## 安装「登录后自动启动」（强烈建议）

出门时你不会一直开着终端。请安装用户级登录后自动启动（先装好 Tailscale 再开服务）。

方式 A：向导里点「安装自动启动」。方式 B：在项目目录用自带脚本：

```bash
npm run install:always-on
npm run uninstall:always-on
```

说明：
- Mac：写入当前用户的登录启动项（launchd LaunchAgent），登录后自动启动
- Windows：创建当前用户的计划任务（Scheduled Task），登录后自动启动
- Linux：测试用的轻量保活（记录进程号 + 后台挂起），不是给用户装的发行包装
- 会打开「允许经 Tailscale 访问本机端口」，Tailscale才能访问服务端口；仍需配对令牌才能聊天

### 运行环境（Node.js）准备
- 需要 Node.js 18 或更高（终端执行 `node -v` 查看）
- Windows 安装时勾选加入 PATH（环境变量）

### 防火墙 / 睡眠风险
- Windows 防火墙若拦截，请允许 Node 访问网络
- 关机或睡眠则出门不可用：电脑须保持开机未睡眠；不会唤醒已睡眠/关机的电脑

## 验收
- 三平台有安装/卸载脚本；网络信息接口能回报系统与自动启动方式（platform / method）；向导按系统分支文案；改动推送到公开仓库。
