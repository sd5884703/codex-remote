# 规格：编码遥控 · 第一期（出门主路径 + Tailscale易用部署）

## 目标（成功标准）
非开发用户完成首次向导后：
1. 明确选择「启用外出访问：Tailscale（在自己的设备之间建立加密私有网络）」或跳过（跳过须用通俗中文写明出门将不可用）。
2. 按屏幕逐步完成：电脑安装/打开 Tailscale、手机安装并同一账号登录（程序不能替用户点完第三方登录，但步骤必须逐步可操作、中文、无未解释英文缩写）。
3. 遥控服务支持「登录后自动启动」（Mac 可用登录启动项 / launchd；最小可用即可）。
4. 向导结束页用通俗中文汇报：做了什么、是否已自动启动、手机应保存的**稳定地址**（Tailscale IP 或魔术域名 Magic DNS，不是家里 Wi‑Fi 地址）、配对令牌是否沿用。
5. 《使用说明》改为**出门主叙事**；家里局域网降为次要/附录。公开隧道（Cloudflare）降为备选，不抢主路径。
6. 手机侧：可一键填入/保存「外出地址」；连不上时区分：电脑服务未开 / Tailscale未在线 / 地址或配对令牌不对（中文）。

## 非目标（本期不做）
- 自动完成 Tailscale 账号注册/付款（只引导）。
- 唤醒已睡眠/关机的电脑。
- 多命令行助手（例如 Claude）适配。
- 安卓安装包（`.apk`）。
- 把 Cloudflare 做成与 Tailscale 同级的易用主路径。

## 用户约束
- 简体中文；禁止甩未解释英文简称（Tailscale 首次出现写「Tailscale」）。
- 主场景=出门；不要把家里 Wi‑Fi 写成默认成功路径。
- 交付物用通俗中文；改动最小，跟随现有架构（电脑服务 daemon + `public/` 网页）。

## 建议落地（实现可调整，验收不变）
1. **首次/联网向导改造**（`setup.html` / `wizard.js` / `i18n`）：外出访问为首屏；步骤拆成可勾选完成的清单；检测本机是否已装/已登录 Tailscale（若可检测则显示已满足，否则给下载链接与「我已装好，下一步」）。
2. **稳定地址**：向导或主界面提供「填入Tailscale地址」：若电脑服务能读到Tailscale IP 则展示并一键复制带配对令牌的配对链接；手机保存到浏览器本地存储（localStorage）。
3. **常驻**：提供安装脚本（或等价）写入用户级登录启动项；向导里安装/卸载常驻；文档写清如何关掉。
4. **说明**：重写 `docs/使用说明.md` 出门主路径；阿验将走查。
5. **安全**：配对令牌仍必填；不在日志打印完整令牌。

## 验收（阿测）
- 向导文案完整中文可走完（可用模拟勾选）。
- 有常驻安装脚本且说明清楚。
- 主界面能保存并重连「非局域网」形式服务器地址。
- 默认不破坏现有局域网与假桥（stub）测试路径。

## 验收（阿验）
- 按新《使用说明》从零走「外出访问」主流程文档走查。
