# 规格：编码遥控 · 第一期（出门主路径 + Tailscale 傻瓜部署）

## 目标（成功标准）
非开发用户完成首次向导后：
1. 明确选择「启用出门通道（Tailscale）」或跳过（跳过须用人话写明出门将不可用）。
2. 按屏幕逐步完成：Mac 安装/打开 Tailscale、手机安装并同一账号登录（程序不能替用户点完第三方登录，但步骤必须逐步可操作、中文、无未解释英文缩写）。
3. 遥控服务支持「登录后常开」（Mac 可用 launchd / 登录项方案；最小可用即可）。
4. 向导结束页用人话汇报：做了什么、是否常开、手机应保存的**稳定地址**（Tailscale IP/魔术DNS，不是家里 Wi‑Fi 地址）、配对钥匙是否沿用。
5. 《使用说明》改为**出门主叙事**；家里局域网降为次要/附录。Cloudflare 隧道降为备选，不抢主路径。
6. 手机侧：可一键填入/保存「出门地址」；连不上时区分：电脑服务未开 / Tailscale 未在线 / 地址或钥匙不对（中文）。

## 非目标（本期不做）
- 自动完成 Tailscale 账号注册/付款（只引导）。
- 唤醒已睡眠/关机的 Mac。
- 多 CLI（Claude）适配。
- 安卓 APK。
- 把 Cloudflare 做成与 Tailscale 同级的傻瓜主路径。

## 用户约束
- 简体中文；禁止甩未解释英文简称（Tailscale 首次出现写「私人组网（Tailscale）」）。
- 主场景=出门；不要把家里 Wi‑Fi 写成默认成功路径。
- 交付物用人话；改动最小，跟随现有架构（daemon + public 网页）。

## 建议落地（实现可调整，验收不变）
1. **首次/联网向导改造**（setup.html / wizard.js / i18n）：出门通道为首屏；步骤拆成可勾选完成的清单；检测本机是否已装/已登录 Tailscale（若可检测则显示已满足，否则给下载链接与「我已装好，下一步」）。
2. **稳定地址**：向导或主界面提供「填入私人组网地址」：若 daemon 能读到 Tailscale IP 则展示并一键复制带 token 的配对链接；手机保存到 localStorage。
3. **常驻**：提供 scripts/install-launch-agent.sh（或等价）安装用户级 launchd；向导里安装/卸载常驻；文档写清如何关掉。
4. **说明**：重写 docs/使用说明.md 出门主路径；阿验将走查。
5. **安全**：配对令牌仍必填；不在日志打印完整 token。

## 验收（阿测）
- 向导文案完整中文可走完（可用模拟勾选）。
- 有常驻安装脚本且说明清楚。
- 主界面能保存并重连「非局域网」形式服务器地址。
- 默认不破坏现有局域网与假 stub 测试路径。

## 验收（阿验）
- 按新《使用说明》从零走「出门通道」主流程文档走查。
