# 编码遥控 — 使用说明

面向普通人：照着下面做，用**出门通道**（私人组网（Tailscale））把「手机遥控家里电脑上的本地编码助手」用起来（支持 Mac 与 Windows）。

**主路径 = 出门 + 私人组网（Tailscale）**。家里同一 Wi‑Fi 只是附录。Cloudflare 隧道只是备选进阶，不是傻瓜主路径。

---

## 你拿到的是什么

- **网页应用**：在 Mac 上跑一个小服务，用手机浏览器打开页面使用。
- **可以加到手机桌面**，但**没有安卓安装包（.apk）**。
- 手机发文字/语音 → Mac 守护进程 → 本机 Codex。模型密钥只留在 Mac。

---

## 使用前准备

| 需要什么 | 说明 |
|---|---|
| 一台 Mac 或 Windows 电脑 | 用来跑服务（产品主平台）；Linux 仅箱测 |
| 本项目 | 例如 Mac `/Users/你/GorkCode/codex-remote` 或 Windows 下的对应目录 |
| Node.js 18+ | 终端 `node -v` 能看到版本 |
| 私人组网（Tailscale）账号 | Mac 与手机同一账号（免费个人版通常够用） |
| （可选）本机 Codex 命令 | 没有也能打开页面、完成配对；对话时若提示找不到，属于环境缺命令 |

## 主流程：出门通道（推荐）

### 1. 在电脑上安装依赖并启动一次

```bash
cd /Users/你的用户名/GorkCode/codex-remote
npm install
npm start
```

用电脑浏览器打开：`http://127.0.0.1:8787/setup.html` 进入**出门通道向导**（也可点应用里的「联网设置」）。

### 2. 向导里勾选「启用出门通道：私人组网（Tailscale）」

- 若**跳过**，向导会明确写：**出门不可用**（只能在家里同一 Wi‑Fi 用，见附录）。
- 我们**不能替你登录** Tailscale，只能给你可操作的中文步骤。

### 3. 按清单安装并登录私人组网（Tailscale）

1. **电脑（Mac / Windows）**：打开 [Tailscale 下载页](https://tailscale.com/download) 或 App Store，安装并登录。
2. **手机**：安装 Tailscale，用**同一个账号**登录。
3. 确认两端在 Tailscale 里都显示已连接 / 在线。
4. 记下电脑的**组网地址**（一般是 `100.x.x.x`，或魔术 DNS 名称）。
   - **手机要保存的是这个地址**，不是家里 Wi‑Fi 的 `192.168.x.x`。
5. 在向导勾选「我已装好，下一步」。

向导若检测到本机已有组网 IP，会显示「已检测到…」。

### 4. 安装「登录后常开」（强烈建议）

出门时你不会一直开着终端。请安装用户级登录后常开（先组网再开服务）。

方式 A：向导里点安装常开。方式 B：用项目自带的安装与卸载脚本。

说明：
- Mac：launchd LaunchAgent，登录后自动启动
- Windows：用户级计划任务（Scheduled Task），登录后自动启动
- Linux：箱测 QA keepalive（非发行版包装）
- 会打开对外监听，私人组网才能访问端口；仍需配对令牌

#### Node 准备
- 需要 Node.js 18+（node -v）
- Windows 安装时勾选加入 PATH

#### 防火墙 / 睡眠风险
- Windows 防火墙若拦截，请允许 Node 访问网络
- 关机或睡眠则出门不可用：电脑须保持开机未睡眠；不会唤醒已睡眠/关机的电脑。

### 5. 看结束页：保存稳定地址到手机

向导结束页会用人话说明：

- 做了什么（是否启用出门、是否常开）
- **手机应保存的稳定地址**（组网 IP / 魔术 DNS + 端口，默认 `8787`）
- 配对钥匙沿用 `~/.codex-remote/config.json` 里的 `pairToken`（也可看终端二维码 / Pair 链接）

在手机浏览器打开例如：

`http://100.x.x.x:8787/?token=你的配对令牌`

或在应用里填：

- **服务器地址**：`http://100.x.x.x:8787`
- **配对令牌**：那一长串钥匙

点「保存」，再点「连接」。也可用主界面「填入出门地址」（需当前页能访问到 Mac 上的服务并已检测到组网 IP）。

### 6. 加到手机桌面（没有安装包时的「安装」）

- **iPhone（Safari）**：分享 → 添加到主屏幕
- **安卓（Chrome）**：菜单 → 添加到主屏幕 / 安装应用

## 连不上时怎么区分（中文）

应用会尽量区分：

| 提示 | 含义 | 你怎么做 |
|---|---|---|
| **服务未开** | Mac 上编码遥控没在跑 | 执行 `npm start`，或确认已 `npm run install:always-on` 且已登录 |
| **组网未在线** | 私人组网（Tailscale）可能断了 | 手机与电脑都打开 Tailscale，确认在线后再连 |
| **地址或钥匙不对** | URL 或配对令牌错误 | 用组网地址（不是家里 Wi‑Fi）；令牌与 `pairToken` 一致 |

---

## 安全提醒（简短）

- 配对令牌 = 钥匙：不要发到公开群。
- 打开对外监听后，能进到你组网/局域网的人可能发现端口，但**没有令牌不能聊天**。
- 终端里完整 Pair 链接含令牌；日常日志尽量不打印完整令牌。

## 附录 A：家里局域网（同一 Wi‑Fi）

仅当手机与电脑 **连同一个 Wi‑Fi** 时可用。**不能代替出门。**

1. 配置 `~/.codex-remote/config.json` 中 `exposeLan` 为 `true`（安装常开时会自动打开）。
2. `npm start` 或依赖常开。
3. 手机用终端里的 **LAN** 地址（如 `http://192.168.x.x:8787`）+ 配对令牌。

访客网络、公司隔离网络常会导致互访失败。

---

## 附录 B：备选进阶 — Cloudflare 隧道

**不是**傻瓜主路径。仅在你无法使用私人组网（Tailscale）时考虑。

1. 按官方文档安装 `cloudflared`
2. 创建隧道，入口指向本机 `8787`（建议 http2）
3. 务必保留配对令牌；建议给隧道加 Access 门禁

应用内「联网设置」结束页也有简要步骤。中国大陆延迟/稳定性可能较差。

## 常用界面按钮

| 你看到的字 | 做什么 |
|---|---|
| 连接 / 断开 | 连上或断开与 Mac 服务的实时通道 |
| 保存 | 记住服务器地址和配对令牌 |
| 填入出门地址 | 尝试填入检测到的组网稳定地址 |
| 复制配对链接 | 复制带令牌的链接 |
| 联网设置 | 出门通道向导（主路径） |
| 清空会话 | 清掉当前对话记录 |

## 「环境缺命令」和「产品/文档问题」

| 现象 | 归类 |
|---|---|

| 按本文步骤，界面没有对应按钮或照做必失败 | **文档或产品问题** |

## 停止服务

- 临时 `npm start`：在终端按 `Control + C`
- 常开：`npm run uninstall:always-on`
