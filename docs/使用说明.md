# 编码遥控：使用说明

照着做，就能用手机遥控家里电脑上的本地编码助手。

## 你能做什么

- 出门在外也能连上家里电脑，发文字（可选语音）。
- 靠 Tailscale（在自己的设备之间建立加密私有网络）连通：在自己的手机和电脑之间拉一条加密通道，只给自己的设备互访。不是普通「翻墙」。
- 家里同一 Wi‑Fi 也能用，但那是备用（见附录）。主推荐是出门场景。
- 形态：手机浏览器打开的网页，可加到桌面。没有安卓安装包（`.apk`）。
- 模型相关密钥只留在家里电脑，不进手机。

电脑支持 Mac 与 Windows。两边步骤大体相同，有差别处会分开写。

## 开始前要有什么

| 你需要 | 说明 |
|---|---|
| 家里电脑 | Mac 或 Windows，能开机 |
| 本项目文件夹 | 电脑上已有「编码遥控」目录 |
| 运行环境（Node.js） | 用来跑这个小服务。Mac 打开「终端」，Windows 打开 PowerShell 或「命令提示符」，输入 `node -v`。能看到版本号即可（建议 18 或更高） |
| Tailscale 账号 | 电脑和手机登录同一个账号 |
| （可选）本地编码命令 `codex` | 没有也能先完成配对连接；发消息时报「找不到」= 电脑环境还没装好，不是你没按说明做 |

## 主流程：出门 + Tailscale

顺序：**先装好 Tailscale，再启用「登录后自动启动」（登录电脑后自动启动本服务）**。

### 第 1 步：在电脑启动一次服务

1. 打开终端（Mac：启动台搜「终端」；Windows：开始菜单搜 PowerShell 或「命令提示符」）。
2. 进入项目文件夹（改成你的真实路径）：

Mac：

```bash
cd /Users/你的用户名/GorkCode/codex-remote
```

Windows：

```bat
cd C:\Users\你的用户名\GorkCode\codex-remote
```

3. 第一次先装依赖（做一次即可）：

```bash
npm install
```

4. 启动：

```bash
npm start
```

5. 别关这个窗口。关掉服务就停了。
6. 在同一台电脑浏览器打开：`http://127.0.0.1:8787/setup.html`  
   进入「设置向导」。也可先打开对话页，再点「联网设置」。

### 第 2 步：勾选外出访问

勾选「启用外出访问：Tailscale」。

跳过不勾选时，向导会写明出门不可用，手机只能在家里同一 Wi‑Fi 用（见附录）。我们不能替你登录账号，只会给可点的中文步骤。

### 第 3 步：安装并登录 Tailscale

1. 电脑：
   - Mac：打开 [Tailscale 下载页](https://tailscale.com/download)，或用 App Store 安装，打开并登录。
   - Windows：打开 [Tailscale 下载页](https://tailscale.com/download) 安装并登录。不要走微软商店 / App Store。
2. 手机：安装 Tailscale，用同一个账号登录。
3. 确认电脑和手机在 Tailscale 里都显示已连接 / 在线。
4. 在电脑 Tailscale 里记下这台电脑的 Tailscale 地址：一般是 `100.` 开头，或「魔术域名」（Magic DNS，好记的名字）。手机要保存这个，不是家里 Wi‑Fi 常见的 `192.168.` 地址。
5. 回到向导，点「我已装好，下一步」。若已检测到 Tailscale 地址，页面可能显示「已检测到…」。

### 第 4 步：装「登录后自动启动」

出门时通常不会一直开着终端。装上之后：你登录电脑，编码遥控会在后台自动跑。

先完成上一步 Tailscale，再启用登录后自动启动。

- 方式 A：向导「登录后自动启动」页点「安装自动启动」。
- 方式 B：仍在项目文件夹执行：

```bash
npm run install:always-on
```

会发生什么：

- Mac：写入当前用户的登录启动项，登录后自动启动。
- Windows：创建当前用户的计划任务，登录后自动启动。
- 会打开「允许经 Tailscale 访问本机端口」，手机才能从 Tailscale 连进来。
- 仍要配对令牌：没有配对令牌不能聊天。

卸载：向导点「卸载自动启动」，或执行：

```bash
npm run uninstall:always-on
```

注意：

- Windows：安装 Node.js 时勾选加入 PATH（环境变量）。防火墙若拦截，允许访问网络。
- 关机或睡眠后，外出访问不可用。电脑须保持开机且未睡眠；本服务不会唤醒已睡眠或关机的电脑。

### 第 5 步：把稳定地址存到手机

向导结束页会写：做了什么（是否启用出门、是否已自动启动），以及手机应保存的稳定地址（Tailscale 地址 + 端口，默认 `8787`）。

读不到 Tailscale 地址时：

1. 打开电脑上的 Tailscale，查看 `100.` 地址或魔术域名。
2. 在手机手动填写，例如 `http://100.x.x.x:8787`。
3. 再填配对令牌（配置里的那一段密钥字符串）。

配对令牌位置：用户目录下 `.codex-remote` 文件夹里配置文件中的配对令牌字段（也可看启动时终端里的配对链接或二维码）。链接里带完整令牌，别发公开群。

手机浏览器可打开：

`http://100.x.x.x:8787/?token=你的配对令牌`

或在页面填写「服务器地址」和「配对令牌」，点「保存」再点「连接」。本机若检测到 Tailscale 地址，也可点「填入外出地址」；检测不到就手动填。

连上后顶部应显示「已连接」。发一条文字试一下：电脑已装 `codex` 会出回复；未装会提示找不到，那是环境未准备好。

### 第 6 步：加到手机桌面

没有安卓安装包。

- iPhone（Safari）：分享 → 添加到主屏幕
- 安卓（Chrome 等）：菜单 → 添加到主屏幕 / 安装应用

桌面图标打开的仍是这个网页。

## 连不上时

| 提示 | 含义 | 你可以怎么做 |
|---|---|---|
| 服务未开 | 家里电脑上的编码遥控没在跑 | 再执行 `npm start`，或确认已装「登录后自动启动」且已登录电脑 |
| Tailscale 未在线 | Tailscale 可能断了 | 手机与电脑都打开 Tailscale，确认两端在线后再连 |
| 地址或配对令牌不对 | 网址或配对令牌填错 | 用 Tailscale 地址（不是 `192.168.`）；令牌与配置文件里的配对令牌一致 |

## 安全

- 配对令牌别发公开群。
- 打开经 Tailscale 可访问后，能进入你的 Tailscale 网络的人可能发现端口，但没有配对令牌不能聊天。
- 终端里带完整配对令牌的配对链接，只给自己的手机用。

## 附录 A：家里同一 Wi‑Fi（备用）

仅当手机与电脑连同一个 Wi‑Fi。不能代替外出访问。

1. 装「登录后自动启动」时，一般会自动允许局域网访问；只用临时启动时，以向导为准打开对外访问。
2. 启动服务（`npm start`）或依赖登录后自动启动。
3. 手机用终端里打印的局域网地址（常见 `http://192.168.x.x:8787`）加配对令牌。

访客网、公司隔离网常常互访不了。

## 附录 B：公开隧道 Cloudflare（进阶，非主路径）

只有用不了 Tailscale 时再考虑。需自行按官方说明装隧道工具，把流量指到本机端口 `8787`，保留配对令牌并尽量加身份门禁。「联网设置」结束页有简要提示。在中国大陆延迟和稳定性可能较差。

## 界面按钮

| 你看到的字 | 做什么 |
|---|---|
| 连接 / 断开 | 连上或断开与家里电脑的通道 |
| 保存 | 记住服务器地址和配对令牌 |
| 填入外出地址 | 填入检测到的 Tailscale 稳定地址 |
| 复制配对链接 | 复制带配对令牌的链接（勿发公开群） |
| 联网设置 | 打开设置向导 |
| 清空会话 | 清掉当前对话 |

## 环境问题还是说明问题

| 现象 | 归类 |
|---|---|
| 能连上，发送后提示找不到本地编码命令 | 环境未准备好：先在电脑装好 `codex` |
| 按本文步骤，界面没有对应按钮，或照做必然失败 | 说明或产品问题 |

## 关掉服务

- 临时启动：在那个终端按 `Control + C`。
- 已启用登录后自动启动：`npm run uninstall:always-on`，或向导里点「卸载自动启动」。
